# Mini-Redis 学习文档

写给刚学完 Go 基础语法、想把知识串起来的人。每一章讲一组 Go 的核心知识，再到 Mini-Redis 的代码里看它们是怎样用的。学完每一章，都应该能开口回答一组面试题。

## 每章的结构

1. **这一章能回答的面试题**：先看问题，带着问题读。
2. **跑起来看什么**：先在项目里看到现象。
3. **Go 基础**：本章用到的语法和标准库，每个例子都能直接运行，输出写在代码末尾的注释里。
4. **代码走读**：在 Mini-Redis 里找到这些知识，逐段读代码。
5. **Go 八股**：每题先给“一分钟口述版”，就是面试时可以直接说的话；再给要点、项目里的例子和常见追问。项目里没有直接用到的知识会标明“项目里没有直接体现，但面试常问”。
6. **关键设计与为什么**：项目里的取舍，为什么这样做、放弃了什么。
7. **动手实验**：亲手改代码、跑命令，看结果。很多实验是“故意改坏一处，看测试怎样报错”。
8. **常见误区**。
9. **自测**：答案折叠着，先自己答再展开。
10. **开发过程回放**：按 git 历史整理的真实经过。
11. **核对来源**：每个说法出自 Go 1.27.1 的哪段源码或文档，或者是哪一次实际运行。

## 做实验之前

- 所有命令都在仓库根目录运行，需要 Go 1.26 或更高版本。文档里的输出来自 Windows、AMD Ryzen 7 9700X、Go 1.27.1；你的机器上数字会不同，规律应该一样。
- 需要写临时程序的实验，放在仓库里的 `tmpexp/` 目录（用 `go run ./tmpexp/xxx` 运行），做完删掉。
- 需要改项目代码的实验，做完用 `git checkout -- <文件>` 改回来，再跑一遍 `go test ./...` 确认恢复了。
- Windows 上运行 `-race` 需要 `CGO_ENABLED=1`，并且能找到 gcc。
